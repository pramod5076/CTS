# Jenkins

## Introduction

Jenkins is an open-source automation server widely used for Continuous Integration and Continuous Delivery (CI/CD).

---

## Features

- Open source
- Pipeline as Code
- Large plugin ecosystem
- Distributed builds
- Integration with Git, Docker, Kubernetes, Maven, Gradle, and more

---

## Advantages

- Highly customizable
- Large community support
- Easy integration with DevOps tools
- Supports automated testing and deployment
