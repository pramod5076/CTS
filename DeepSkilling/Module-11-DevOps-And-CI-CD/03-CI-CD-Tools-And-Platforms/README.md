# CI/CD Tools and Platforms

## Overview

CI/CD tools automate software building, testing, and deployment. They help development teams deliver software faster, improve quality, and reduce manual effort.

This module covers:

- Overview of CI/CD Tools
- Jenkins
- GitHub Actions
- GitLab CI/CD
- CircleCI

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand the purpose of CI/CD tools.
- Describe Jenkins and its features.
- Explain GitHub Actions.
- Understand GitLab CI/CD.
- Describe CircleCI and its capabilities.
