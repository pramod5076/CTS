# GitHub Actions

## Introduction

GitHub Actions is GitHub's built-in CI/CD platform used to automate workflows directly from GitHub repositories.

---

## Features

- Workflow automation
- YAML-based configuration
- GitHub integration
- Supports multiple operating systems
- Marketplace for reusable actions

---

## Advantages

- No separate CI server required
- Easy GitHub integration
- Automatic workflow execution
- Suitable for open-source and enterprise projects
