# What is Continuous Delivery and Continuous Deployment (CD)?

## Continuous Delivery

Continuous Delivery ensures that software is always in a deployable state.

After successful testing, deployment to production is performed manually.

---

## Continuous Deployment

Continuous Deployment automatically deploys every successful code change to production without manual approval.

---

## Key Features

- Automated deployment pipeline
- Reliable software releases
- Faster release cycles
- Reduced manual intervention
