# Differences Between CI and CD

| Continuous Integration (CI) | Continuous Delivery / Deployment (CD) |
|------------------------------|----------------------------------------|
| Focuses on integrating code frequently. | Focuses on delivering and deploying software. |
| Automates build and testing. | Automates software release process. |
| Detects integration issues early. | Delivers software quickly to users. |
| Developers commit code frequently. | Deployment occurs after successful testing. |
| Improves code quality. | Improves release speed and reliability. |
