# What is Generative AI?

Generative AI (GenAI) is a type of Artificial Intelligence that generates new content by learning patterns from existing data.

Unlike traditional AI systems that classify or predict, Generative AI can create original outputs such as:

- Text
- Images
- Source code
- Audio
- Video

It uses advanced machine learning models, particularly **Large Language Models (LLMs)** and **Generative Models**, to understand prompts and generate meaningful responses.

## Key Characteristics

- Content generation
- Natural language understanding
- Creativity assistance
- Learning from large datasets
- Human-like interactions
