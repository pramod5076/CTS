# Introduction to Generative AI

## Overview

Generative AI (GenAI) is a branch of Artificial Intelligence that creates new content such as text, images, code, audio, and videos by learning patterns from existing data. Unlike traditional AI, which mainly classifies or predicts outcomes, Generative AI produces original content based on user prompts.

This module covers:

- What is Generative AI?
- Generative AI vs Traditional AI
- Applications of Generative AI
- History and Evolution of Generative AI
