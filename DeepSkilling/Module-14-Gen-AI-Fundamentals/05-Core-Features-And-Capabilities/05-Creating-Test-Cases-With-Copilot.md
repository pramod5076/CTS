# Creating Test Cases with Copilot

GitHub Copilot can generate unit tests for existing code.

## Example Prompt

```text
Generate NUnit test cases for the following C# method.
```

## Copilot Can Generate

- Positive test cases
- Negative test cases
- Boundary value tests
- Exception handling tests

## Advantages

- Saves testing time
- Improves code reliability
- Increases test coverage
- Helps identify edge cases
