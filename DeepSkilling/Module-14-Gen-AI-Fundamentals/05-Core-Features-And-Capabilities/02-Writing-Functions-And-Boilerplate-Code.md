# Writing Functions and Boilerplate Code

GitHub Copilot can generate functions from natural language comments.

## Example

```csharp
// Create a method to calculate the average of an integer array.
```

Copilot generates the corresponding C# method.

## Boilerplate Code Examples

- Class definitions
- Constructors
- Interfaces
- CRUD methods
- API controllers
- Loops and conditionals

This reduces the time spent writing repetitive code.
