# Best Practices

Effective prompts improve the quality of AI-generated responses.

## Best Practices

- Write clear and specific instructions.
- Provide enough context for the task.
- Specify the expected output format.
- Mention programming language if generating code.
- Break complex tasks into smaller prompts.
- Refine prompts based on previous responses.
- Avoid vague or ambiguous wording.

## Example

Instead of:

```text
Write code.
```

Use:

```text
Write a C# method that returns the factorial of a number using recursion. Include comments and explain the time complexity.
```
