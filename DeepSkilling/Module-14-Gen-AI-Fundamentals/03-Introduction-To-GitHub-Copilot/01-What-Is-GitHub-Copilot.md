# What is GitHub Copilot?

GitHub Copilot is an AI-powered coding assistant developed by **GitHub** in collaboration with **OpenAI**.

It helps developers by suggesting code, completing functions, generating documentation, and assisting with programming tasks directly inside the code editor.

GitHub Copilot acts as an **AI pair programmer**, helping developers write code more efficiently.

## Benefits

- Faster code development
- Reduced repetitive coding
- Improved productivity
- Learning new programming languages
- Code suggestions in real time
