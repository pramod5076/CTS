# Supported IDEs and Languages

GitHub Copilot integrates with several popular Integrated Development Environments (IDEs).

## Supported IDEs

- Visual Studio Code
- Visual Studio
- JetBrains IDEs
- Neovim

## Commonly Supported Languages

- C#
- Python
- Java
- JavaScript
- TypeScript
- C++
- Go
- PHP
- Ruby
- Kotlin
- Swift

GitHub Copilot supports many other programming languages and continues to expand its capabilities.
