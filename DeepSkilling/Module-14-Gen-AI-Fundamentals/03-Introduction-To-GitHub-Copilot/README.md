# Introduction to GitHub Copilot

## Overview

GitHub Copilot is an AI-powered coding assistant that helps developers write code faster by providing intelligent code suggestions, completing functions, generating documentation, and assisting with debugging. It acts as an AI pair programmer inside supported code editors.

This module covers:

- What is GitHub Copilot?
- Features of GitHub Copilot
- How GitHub Copilot Works
- Supported IDEs and Programming Languages

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand GitHub Copilot.
- Explain its key features.
- Describe how GitHub Copilot generates code suggestions.
- Identify supported development environments and programming languages.
