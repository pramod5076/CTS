# How GitHub Copilot Works

GitHub Copilot works by analyzing the code, comments, and context within the current file.

It uses AI models trained on publicly available source code and natural language to predict and suggest the next lines of code.

## Workflow

1. Developer writes code or comments.
2. Copilot analyzes the surrounding context.
3. AI predicts the most relevant code.
4. Suggestions are displayed in the editor.
5. Developer accepts, edits, or ignores the suggestion.

## AI Pair Programmer

GitHub Copilot functions as an AI pair programmer by assisting with coding tasks while allowing developers to retain full control over the final implementation.
