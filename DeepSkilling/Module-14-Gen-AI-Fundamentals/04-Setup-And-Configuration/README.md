# Setup and Configuration

## Overview

Before using GitHub Copilot, it must be installed and connected to a GitHub account. Once configured, developers can start using AI-powered code suggestions directly within Visual Studio Code.

This module covers:

- Installing the GitHub Copilot extension
- Connecting to a GitHub account
- Creating the first coding task using Copilot

---

## Learning Outcomes

After completing this module, you will be able to:

- Install GitHub Copilot in Visual Studio Code.
- Sign in with a GitHub account.
- Enable GitHub Copilot.
- Use Copilot to generate code for a simple programming task.
