# First Coding Task with Copilot

After setup, you can use GitHub Copilot to generate code suggestions.

## Example Task

Create a new C# file and type the following comment:

```csharp
// Write a C# method to calculate the factorial of a number.
```

GitHub Copilot will suggest an implementation based on the comment.

## Another Example

```csharp
// Create a class named Student with Name and Age properties.
```

Copilot will generate a class definition automatically.

## Tips

- Write clear comments describing the required functionality.
- Review AI-generated code before accepting it.
- Test generated code to ensure correctness.
- Modify suggestions as needed to match project requirements.
