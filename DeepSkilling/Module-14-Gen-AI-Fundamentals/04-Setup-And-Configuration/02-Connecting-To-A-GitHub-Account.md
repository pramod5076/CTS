# Connecting to a GitHub Account

After installing the extension, GitHub Copilot must be linked to your GitHub account.

## Steps

1. Open Visual Studio Code.
2. Launch the GitHub Copilot extension.
3. Click **Sign In**.
4. A browser window will open.
5. Log in using your GitHub account.
6. Authorize Visual Studio Code to access GitHub Copilot.
7. Return to Visual Studio Code after successful authentication.

Once connected, GitHub Copilot is ready to provide AI-assisted coding suggestions.
