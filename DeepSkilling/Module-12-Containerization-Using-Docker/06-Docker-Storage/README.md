# Docker Storage

## Overview

Docker storage enables containers to persist and manage data efficiently. Docker provides storage drivers and volumes that allow data to survive container restarts and improve storage management.

This module covers:

- Storage Drivers
- Data Volumes
- Changing the Storage Driver for a Container
- Creating a Volume
- Listing All Volumes

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand Docker storage drivers.
- Explain Docker data volumes.
- Change storage drivers.
- Create Docker volumes.
- List available Docker volumes.
