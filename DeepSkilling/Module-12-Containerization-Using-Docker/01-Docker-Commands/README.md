# Docker Commands

## Overview

Docker provides a set of commands to create, manage, and remove containers and images. These commands are essential for working with Docker containers in development and deployment environments.

This module covers:

- Basic Docker Commands
- docker run
- docker ps
- docker stop
- docker rm
- docker images
- docker rmi
- docker pull
- Append a Command
- docker exec

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand commonly used Docker commands.
- Run and manage Docker containers.
- List and remove containers.
- Manage Docker images.
- Execute commands inside running containers.
