# Basic Docker Commands

Docker commands help users create, manage, inspect, and remove containers and images.

## Common Commands

| Command | Description |
|----------|-------------|
| docker run | Create and start a container |
| docker ps | List running containers |
| docker stop | Stop a running container |
| docker rm | Remove a container |
| docker images | List Docker images |
| docker rmi | Remove an image |
| docker pull | Download an image |
| docker exec | Execute commands inside a running container |

These commands form the foundation of Docker container management.
