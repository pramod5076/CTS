# Docker Engine

## Overview

Docker Engine is the core runtime responsible for building, running, and managing Docker containers. It consists of the Docker CLI, Docker REST API, and Docker Daemon, which work together to provide containerization capabilities.

This module covers:

- What is Docker Engine?
- Docker CLI
- Docker REST API
- Docker Daemon

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand Docker Engine and its architecture.
- Explain the role of Docker CLI.
- Describe the Docker REST API.
- Understand the responsibilities of the Docker Daemon.
