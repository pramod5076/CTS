# Docker CLI

Docker CLI (Command Line Interface) is the primary tool used to interact with Docker Engine.

Users execute Docker commands through the terminal, and the CLI communicates with the Docker Daemon.

## Common Commands

```bash
docker run
docker build
docker pull
docker push
docker images
docker ps
docker stop
docker rm
```

## Advantages

- Easy to use
- Fast command execution
- Script automation
- Supports all Docker operations
