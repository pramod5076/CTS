# What is Docker Engine?

Docker Engine is the core software that enables users to build, run, and manage Docker containers.

It is a client-server application consisting of:

- Docker Daemon
- Docker REST API
- Docker CLI

Docker Engine provides the runtime environment required to create and manage containers efficiently.

## Features

- Open-source container runtime
- Supports container creation and management
- Platform independent
- Lightweight and portable
- Automates container lifecycle management
