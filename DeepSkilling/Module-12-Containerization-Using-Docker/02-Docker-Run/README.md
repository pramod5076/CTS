# Docker Run

## Overview

The `docker run` command is one of the most commonly used Docker commands. It creates and starts a container from a Docker image. Various options allow users to assign names, run containers in the background, interact with containers, publish ports, and automatically remove containers after execution.

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand the `docker run` command.
- Run a container with a custom name.
- Run containers in detached mode.
- Run containers interactively.
- Publish container ports.
- Automatically remove containers after execution.
