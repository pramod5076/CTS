# Docker Networking

## Overview

Docker Networking enables communication between containers, the host machine, and external networks. Docker provides built-in network drivers and allows users to create custom networks for better isolation and communication.

This module covers:

- Default Networks
- Listing All Docker Networks
- Inspecting a Docker Network
- Creating Your Own New Network

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand Docker networking.
- Identify Docker's default networks.
- List all Docker networks.
- Inspect a Docker network.
- Create and manage custom Docker networks.
