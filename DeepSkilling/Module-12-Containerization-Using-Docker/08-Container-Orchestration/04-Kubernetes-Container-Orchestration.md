# Kubernetes Container Orchestration

Kubernetes is an open-source platform used to automate the deployment, scaling, and management of containerized applications.

It groups containers into units called **Pods** and manages them across a cluster of machines.

## Features

- Automatic scheduling
- Self-healing
- Horizontal scaling
- Rolling updates
- Service discovery
- Load balancing
- Secret and configuration management

Kubernetes is widely used for running large-scale containerized applications.
