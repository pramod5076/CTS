# Container Orchestration versus Docker

| Docker | Container Orchestration (Kubernetes) |
|--------|---------------------------------------|
| Creates and runs containers | Manages multiple containers |
| Suitable for single-host environments | Suitable for multi-host clusters |
| Manual scaling | Automatic scaling |
| Limited container management | Advanced container lifecycle management |
| Focuses on container execution | Focuses on deployment, scaling, networking, and monitoring |

## Summary

Docker is a container platform that packages and runs applications, while Kubernetes is a container orchestration platform that manages containers across multiple systems.
