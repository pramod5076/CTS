# Version Control Concepts

## Definition

Version Control is a software system that records changes to files so that previous versions can be viewed or restored whenever required.

---

## Purpose

The primary purposes of Version Control are:

- Track modifications
- Maintain project history
- Enable teamwork
- Recover deleted or modified files
- Manage multiple versions of a project

---

## Basic Workflow

```
Create Project
      │
      ▼
Modify Files
      │
      ▼
Save Changes
      │
      ▼
Commit Changes
      │
      ▼
Store Version History
      │
      ▼
Collaborate with Team
```

---

## Important Terminology

### Repository (Repo)

A repository stores project files along with their version history.

---

### Commit

A commit is a snapshot of the project at a specific point in time.

---

### Branch

A branch is an independent line of development used to work on features or fixes.

---

### Merge

Merge combines changes from one branch into another.

---

### Clone

Clone creates a local copy of a remote repository.

---

### Pull

Pull fetches the latest changes from a remote repository.

---

### Push

Push uploads local commits to a remote repository.

---

## Summary

Understanding these concepts is essential before learning Git commands and workflows.
