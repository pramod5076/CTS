# Git Ignore Hands-On Lab

## Objective

This hands-on exercise demonstrates how to use the `.gitignore` file to prevent unwanted files and folders from being tracked by Git.

---

## Learning Outcomes

After completing this lab, you will be able to:

- Understand the purpose of `.gitignore`
- Ignore files based on extensions
- Ignore directories
- Verify ignored files using `git status`

---

## Prerequisites

- Git installed
- Git repository initialized
- Git configured
- Remote repository (GitHub/GitLab)
- Notepad++ (optional)
