# Git Clean Up and Push to Remote Git Hands-On Lab

## Step 1

Verify the repository is clean.

```bash
git status
```

---

## Step 2

List all branches.

```bash
git branch -a
```

---

## Step 3

Pull the latest changes.

```bash
git pull origin main
```

---

## Step 4

Stage pending changes.

```bash
git add .
```

Commit changes.

```bash
git commit -m "Updated files in Git-T03-HOL_002"
```

Push changes.

```bash
git push origin main
```

---

## Step 5

Open GitHub and verify that the latest commit appears in the repository.

---

## Result

The local repository is synchronized with the remote GitHub repository.
