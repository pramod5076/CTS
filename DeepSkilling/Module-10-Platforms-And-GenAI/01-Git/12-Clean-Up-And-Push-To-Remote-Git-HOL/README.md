# Git Clean Up and Push to Remote Git Hands-On Lab

## Objective

This hands-on lab demonstrates how to clean up the local repository, synchronize with the remote repository, push pending changes, and verify the updates on GitHub.

---

## Learning Outcomes

After completing this lab, you will be able to:

- Verify repository status
- List local and remote branches
- Pull the latest changes from GitHub
- Push local commits to GitHub
- Verify changes in the remote repository

---

## Prerequisites

- Git installed
- GitHub repository configured
- Previous Git HOL completed
