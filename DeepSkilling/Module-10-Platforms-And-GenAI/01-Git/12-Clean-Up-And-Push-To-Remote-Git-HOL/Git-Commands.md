# Git Commands Used

## Check Repository Status

```bash
git status
```

---

## List Branches

```bash
git branch -a
```

---

## Pull Latest Changes

```bash
git pull origin main
```

---

## Stage Changes

```bash
git add .
```

---

## Commit Changes

```bash
git commit -m "Updated files in Git-T03-HOL_002"
```

---

## Push Changes

```bash
git push origin main
```
