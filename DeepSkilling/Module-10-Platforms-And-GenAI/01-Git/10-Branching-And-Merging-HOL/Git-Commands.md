# Git Commands Used

## Create Branch

```bash
git branch GitNewBranch
```

---

## View Branches

```bash
git branch

git branch -a
```

---

## Switch Branch

```bash
git checkout GitNewBranch

git switch GitNewBranch
```

---

## Check Status

```bash
git status
```

---

## Stage Changes

```bash
git add .
```

---

## Commit

```bash
git commit -m "Added new files in GitNewBranch"
```

---

## Compare Branches

```bash
git diff main GitNewBranch
```

---

## Visual Comparison

```bash
git difftool main GitNewBranch
```

---

## Merge Branch

```bash
git merge GitNewBranch
```

---

## Commit History

```bash
git log --oneline --graph --decorate
```

---

## Delete Branch

```bash
git branch -d GitNewBranch
```

---

## Final Status

```bash
git status
```
