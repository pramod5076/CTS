# Git Branching and Merging Hands-On Lab (HOL)

## Objective

This hands-on lab demonstrates how to work with Git branches by creating a new branch, making changes, committing them, comparing branches, merging into the main branch, and deleting the merged branch.

---

## Learning Outcomes

After completing this lab, you will be able to:

- Create a new branch
- Switch between branches
- Commit changes in a branch
- Compare two branches
- Merge a branch into the main branch
- View commit history
- Delete merged branches

---

## Prerequisites

- Git installed and configured
- Git repository already initialized
- P4Merge installed (optional)
- GitHub repository
