# Understanding Git

## What is Git?

Git is a free and open-source Distributed Version Control System (DVCS) designed to track changes in source code during software development. It enables multiple developers to collaborate on a project while maintaining a complete history of changes.

---

## Why Use Git?

- Tracks changes in source code
- Enables team collaboration
- Maintains version history
- Supports branching and merging
- Allows rollback to previous versions
- Works offline with a local repository

---

## Features of Git

- Distributed architecture
- Fast performance
- Lightweight
- Secure data integrity using SHA hashing
- Easy branching and merging
- Open source
- Cross-platform support
