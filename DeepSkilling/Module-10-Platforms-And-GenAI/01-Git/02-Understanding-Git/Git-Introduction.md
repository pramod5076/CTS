# Introduction to Git

## Definition

Git is a Distributed Version Control System created by **Linus Torvalds** in 2005 to manage the development of the Linux kernel.

---

## Objectives of Git

- Track file changes
- Store project history
- Facilitate collaboration
- Support multiple development branches
- Ensure code integrity

---

## Advantages

- Free and Open Source
- High performance
- Offline functionality
- Efficient branching
- Easy merging
- Strong community support

---

## Common Git Platforms

- GitHub
- GitLab
- Bitbucket
- Azure Repos

---

## Basic Git Workflow

```
Create Project
      │
      ▼
Initialize Git Repository
      │
      ▼
Modify Files
      │
      ▼
Stage Changes
      │
      ▼
Commit Changes
      │
      ▼
Push to Remote Repository
```

---

## Summary

Git is an industry-standard tool used to manage source code efficiently and support collaborative software development.
