# Git Merge Conflict Resolution Hands-On Lab

## Objective

This hands-on lab demonstrates how merge conflicts occur and how to resolve them using Git and a three-way merge tool such as P4Merge.

---

## Learning Outcomes

After completing this lab, you will be able to:

- Create conflicting changes in different branches
- Identify merge conflicts
- Resolve conflicts manually
- Resolve conflicts using P4Merge
- Commit the resolved changes
- Update the `.gitignore` file
- Delete merged branches

---

## Prerequisites

- Git installed and configured
- Previous Git HOL completed
- P4Merge installed
- GitHub repository
