# Basic Git Commands

## Introduction

Git provides a set of commands to manage repositories, track changes, and maintain project history. These commands form the foundation of everyday Git usage.

---

## Topics Covered

- git init
- git clone
- git add
- git commit
- git status
- git log

---

## Basic Git Workflow

```
Create/Open Project
        │
        ▼
git init / git clone
        │
        ▼
Modify Files
        │
        ▼
git add
        │
        ▼
git commit
        │
        ▼
git status
        │
        ▼
git log
```

---

## Why Learn These Commands?

- Initialize repositories
- Copy existing repositories
- Track changes
- Save project versions
- Check repository status
- View commit history

---

## Summary

These commands are the most frequently used Git commands and are essential for every developer.
