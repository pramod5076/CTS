# Git Commands Used

## Installation

```bash
git --version
```

---

## Configuration

```bash
git config --global user.name "Pramod"

git config --global user.email "example@gmail.com"
```

---

## Repository

```bash
git init
```

```bash
git clone <url>
```

---

## Status

```bash
git status
```

---

## Staging

```bash
git add welcome.txt
```

```bash
git add .
```

---

## Commit

```bash
git commit -m "Initial Commit"
```

---

## Remote

```bash
git remote add origin <url>

git remote -v
```

---

## Synchronization

```bash
git pull origin main

git push origin main
```

---

## Log

```bash
git log

git log --oneline
```
