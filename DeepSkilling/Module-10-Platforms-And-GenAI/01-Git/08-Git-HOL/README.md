# Git Hands-On Lab (HOL)

## Objective

This hands-on exercise demonstrates the basic Git workflow including:

- Git installation verification
- Git configuration
- Configuring Notepad++ as the default editor
- Creating a Git repository
- Adding files
- Tracking changes
- Committing changes
- Pulling from a remote repository
- Pushing to a remote repository

---

## Prerequisites

- Git Bash installed
- GitHub/GitLab account
- Notepad++ (optional)
- Internet connection

---

## Files

- Git-HOL.md
- Git-Commands.md
- Expected-Output.md

---

## Learning Outcomes

After completing this lab, you will be able to:

- Configure Git
- Create repositories
- Track files
- Commit changes
- Push code to GitHub/GitLab
- Pull latest changes
