# Branching and Merging

## Introduction

Branching is one of Git's most powerful features. It allows developers to work on new features, bug fixes, or experiments without affecting the main codebase. Once the work is complete, branches can be merged back into the main branch.

## Branching Workflow

```
main
 │
 ├──────────────┐
 │              │
 ▼              ▼
feature/login  feature/dashboard
 │              │
 └──────┬───────┘
        ▼
      main
```

---

## Benefits

- Parallel development
- Safe experimentation
- Better collaboration
- Easy bug fixing
- Organized releases

---

## Summary

Git branching enables multiple developers to work independently while keeping the main branch stable and ready for production.
