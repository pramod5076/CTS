# Installing Git

## Download Git

Download Git from the official website:

https://git-scm.com/

---

## Installation Steps (Windows)

1. Download the latest Git installer.
2. Run the installer.
3. Click **Next** through the setup wizard.
4. Select the default options unless customization is required.
5. Click **Install**.
6. Click **Finish** after installation.

---

## Verify Installation

Open Command Prompt or PowerShell and run:

```bash
git --version
```

Example Output

```text
git version 2.50.1.windows.1
```

---

## Install on Linux

Ubuntu/Debian

```bash
sudo apt update

sudo apt install git
```

---

## Install on macOS

Using Homebrew

```bash
brew install git
```

---

## Verify Again

```bash
git --version
```

---

## Summary

Git installation is straightforward and available for Windows, Linux, and macOS. Always verify the installation before configuring Git.
