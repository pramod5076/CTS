# Setting Up Git

## Introduction

Before using Git for version control, it must be installed and configured on your computer. After installation, you can initialize a new repository or clone an existing repository.

---

## Topics Covered

- Installing Git
- Downloading Git
- Git Installation Steps
- Configuring Git
- Setting Username
- Setting Email
- Creating a Git Repository
- Initializing a Repository
- Cloning an Existing Repository

---

## Prerequisites

- Windows, Linux, or macOS
- Internet Connection
- Administrator Privileges (if required)

---

## Git Setup Workflow

```
Download Git
      │
      ▼
Install Git
      │
      ▼
Verify Installation
      │
      ▼
Configure Username
      │
      ▼
Configure Email
      │
      ▼
Initialize Repository
      │
      ▼
Start Tracking Files
```

---

## Summary

Setting up Git involves installing the software, configuring user information, and creating or cloning repositories for version control.
