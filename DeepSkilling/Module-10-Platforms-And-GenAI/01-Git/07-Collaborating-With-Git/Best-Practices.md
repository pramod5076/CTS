# Best Practices for Git Collaboration

## Repository

- Keep repositories organized.
- Use meaningful repository names.
- Protect important branches.

---

## Branches

- Create one branch per feature or bug fix.
- Use descriptive branch names.
- Delete merged branches.

Examples

```
feature/login

feature/payment

bugfix/navbar

hotfix/security
```

---

## Commits

Write clear commit messages.

Good examples

```
Add login authentication

Fix navigation issue

Update API documentation
```

Avoid

```
Update

Changes

Work
```

---

## Pull Requests

- Keep PRs focused on one task.
- Add meaningful descriptions.
- Request code reviews.
- Resolve comments before merging.

---

## Collaboration

- Pull latest changes regularly.
- Resolve merge conflicts carefully.
- Test before pushing.
- Review code before merging.

---

## Summary

Following Git collaboration best practices improves teamwork, reduces conflicts, and ensures a maintainable project history.
