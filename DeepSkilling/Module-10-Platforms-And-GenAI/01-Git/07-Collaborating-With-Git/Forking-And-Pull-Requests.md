# Forking and Pull Requests

## What is Forking?

Forking creates a personal copy of another user's repository on your Git hosting platform.

Example

```
Original Repository

        │

Fork

        ▼

Your Repository
```

You can freely experiment without affecting the original project.

---

## Why Fork?

- Contribute to open-source projects
- Experiment safely
- Maintain your own copy
- Develop new features independently

---

## What is a Pull Request (PR)?

A Pull Request is a request to merge changes from one branch or fork into another repository.

Typical process:

```
Fork Repository
      │
Clone Repository
      │
Create Branch
      │
Make Changes
      │
Commit
      │
Push
      │
Create Pull Request
      │
Review
      │
Merge
```

---

## Pull Request Benefits

- Code review
- Team discussion
- Automated testing
- Approval before merge
- Better code quality

---

## Managing Pull Requests

- Create a PR
- Add title and description
- Assign reviewers
- Respond to review comments
- Merge after approval
- Delete merged branch

---

## Summary

Forks enable independent development, while Pull Requests provide a structured process for reviewing and merging contributions.
