# Collaborating with Git

## Introduction

Git enables multiple developers to work on the same project efficiently. Collaboration is achieved using repositories, branches, forks, and pull requests. These features help teams contribute code, review changes, and maintain code quality.

---

## Topics Covered

- Forking a Repository
- Pull Requests
- Centralized Workflow
- Feature Branch Workflow
- Forking Workflow
- Gitflow Workflow

---

## Collaboration Workflow

```
Developer
     │
Fork Repository
     │
Clone Repository
     │
Create Branch
     │
Make Changes
     │
Commit Changes
     │
Push Branch
     │
Create Pull Request
     │
Code Review
     │
Merge
```

---

## Benefits

- Team collaboration
- Code reviews
- Controlled merging
- Parallel development
- Better code quality

---

## Summary

Git collaboration features allow teams to work simultaneously while maintaining a structured and reliable development process.
