# Definition of Done

The **Definition of Done (DoD)** is a shared checklist that defines when a Product Backlog item or Increment is considered complete.

## Typical Criteria

- Code is implemented.
- Code review is completed.
- Unit tests are passed.
- Integration tests are successful.
- Documentation is updated.
- No critical defects remain.
- Product Owner acceptance criteria are satisfied.

## Benefits

- Ensures consistent quality
- Improves transparency
- Reduces technical debt
- Builds confidence in product releases
