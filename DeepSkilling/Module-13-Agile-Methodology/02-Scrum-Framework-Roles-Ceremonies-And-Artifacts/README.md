# Scrum Framework – Roles, Ceremonies & Artifacts

## Overview

Scrum is an Agile framework used to develop, deliver, and maintain complex products. It organizes work into short iterations called **Sprints** and defines specific roles, ceremonies, and artifacts to improve collaboration, transparency, and product quality.

This module covers:

- Scrum Roles
- Scrum Ceremonies
- Scrum Artifacts
- Definition of Done

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand the Scrum framework.
- Explain the responsibilities of Scrum roles.
- Describe Scrum ceremonies.
- Identify Scrum artifacts.
- Understand the Definition of Done.
