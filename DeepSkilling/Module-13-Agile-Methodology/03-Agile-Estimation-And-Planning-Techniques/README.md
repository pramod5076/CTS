# Agile Estimation & Planning Techniques

## Overview

Agile estimation and planning techniques help Scrum teams estimate the effort required for user stories, plan Sprint work, and track project progress. Instead of estimating time directly, Agile teams often estimate relative effort using Story Points and collaborative techniques such as Planning Poker.

This module covers:

- Story Points
- Planning Poker
- Sprint Planning Process
- Velocity
- Burndown Charts

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand Story Points.
- Explain the Planning Poker technique.
- Describe the Sprint Planning process.
- Calculate and interpret Velocity.
- Understand Burndown Charts and their purpose.
