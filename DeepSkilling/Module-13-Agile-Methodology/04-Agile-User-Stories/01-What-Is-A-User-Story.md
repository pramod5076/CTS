# What is a User Story?

A User Story is a brief description of a software feature from the perspective of the user who will benefit from it.

It focuses on **who** needs the feature, **what** they need, and **why** they need it.

## Purpose

- Capture customer requirements
- Encourage collaboration
- Focus on user value
- Support iterative development
- Simplify requirement gathering

## Characteristics

- Short and simple
- User-focused
- Easy to understand
- Can be estimated and prioritized
