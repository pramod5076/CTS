# User Story Format

The standard User Story template is:

```text
As a [user],
I want [goal],
So that [benefit].
```

## Example

```text
As a customer,

I want to reset my password,

So that I can regain access to my account if I forget my password.
```

### Components

- **User** – Who needs the feature?
- **Goal** – What functionality is required?
- **Benefit** – Why is the feature valuable?
