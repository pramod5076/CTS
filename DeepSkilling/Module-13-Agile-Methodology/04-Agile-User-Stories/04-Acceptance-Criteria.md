# Acceptance Criteria

Acceptance Criteria define the conditions that must be satisfied for a User Story to be considered complete.

A common format is **Given – When – Then**.

## Structure

- **Given** – Initial context or precondition.
- **When** – Action performed by the user.
- **Then** – Expected outcome.

## Example

```text
Given a registered user,

When the user enters valid login credentials,

Then the system should redirect the user to the dashboard.
```

## Benefits

- Clarifies requirements
- Reduces misunderstandings
- Supports testing
- Defines completion criteria
