# INVEST Principle

A good User Story should follow the **INVEST** principle.

| Letter | Meaning | Description |
|--------|---------|-------------|
| I | Independent | Can be developed independently of other stories. |
| N | Negotiable | Details can be discussed and refined. |
| V | Valuable | Delivers value to the user or business. |
| E | Estimable | Can be estimated by the team. |
| S | Small | Small enough to complete within a Sprint. |
| T | Testable | Can be verified through testing. |

Following INVEST improves the quality and clarity of User Stories.
