# Introduction to Agile & Agile Manifesto

## Overview

Agile is a modern software development methodology that focuses on flexibility, collaboration, customer satisfaction, and continuous improvement. Instead of delivering software at the end of the project, Agile delivers working software in small increments through iterative development.

This module covers:

- Overview of Agile
- Agile Manifesto
- Four Agile Values
- Twelve Agile Principles
- Agile vs Waterfall

---

## Learning Outcomes

After completing this module, you will be able to:

- Understand Agile methodology.
- Explain the Agile Manifesto.
- Describe the four Agile values.
- Understand the twelve Agile principles.
- Compare Agile and Waterfall methodologies.
