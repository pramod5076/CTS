# Debugging Angular with Chrome DevTools

## What is Debugging?

Debugging is the process of finding, analyzing, and fixing errors (bugs) in an application. Angular applications can be debugged using Chrome DevTools together with Angular CLI.

---

## Setting Up the Environment

Install dependencies:

```bash
npm install
```

Run the Angular application:

```bash
ng serve
```

Default URL:

```
http://localhost:4200
```

---

## Why Use Chrome DevTools?

- Inspect HTML and CSS
- Debug JavaScript and TypeScript
- Analyze Network requests
- View Console errors
- Measure application performance
- Debug Angular applications

---

## Chrome DevTools Panels

- Elements
- Console
- Sources
- Network
- Performance
- Memory
- Application
- Lighthouse

---

## Benefits

- Faster debugging
- Better understanding of application behavior
- Easy identification of runtime errors
- Improved performance optimization

---

## Summary

Chrome DevTools is one of the most powerful tools for debugging Angular applications during development.
