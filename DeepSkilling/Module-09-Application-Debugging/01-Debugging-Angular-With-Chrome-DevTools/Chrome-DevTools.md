# Chrome DevTools

## Opening Chrome DevTools

Methods:

- Press **F12**
- Press **Ctrl + Shift + I**
- Right-click → Inspect

---

## Elements Panel

The Elements panel displays the DOM tree of the current webpage.

Features:

- Inspect HTML
- Edit HTML
- Modify CSS
- View applied styles
- View computed styles

---

## Console Panel

The Console is used to:

- Display JavaScript errors
- Execute JavaScript code
- View logs
- Display warnings

Example

```javascript
console.log("Application Started");

console.error("Something went wrong");

console.warn("Warning");
```

---

## Network Panel

Used for

- HTTP Requests
- API Calls
- Response Time
- Status Codes
- Request Headers

---

## Performance Panel

Used to analyze

- Rendering
- JavaScript execution
- CPU usage
- Frame rate

---

## Memory Panel

Helps detect

- Memory leaks
- Heap snapshots
- Garbage collection
