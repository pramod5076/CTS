# Debugging Angular in Visual Studio Code

## Introduction

Visual Studio Code provides powerful debugging capabilities for Angular applications. By using the built-in debugger and Chrome integration, developers can inspect TypeScript code, variables, services, and application state.

---

## Prerequisites

- Node.js
- Angular CLI
- Visual Studio Code
- Angular Language Service Extension
- JavaScript Debugger (built into VS Code)

---

## Development Server

Start the Angular application:

```bash
ng serve
```

Open:

```
http://localhost:4200
```

---

## VS Code Debugging Features

- Breakpoints
- Watches
- Variables
- Call Stack
- Debug Console
- Source Maps
- Step Into
- Step Over
- Step Out

---

## Benefits

- Debug TypeScript directly
- Inspect Angular services
- Analyze application state
- Faster bug detection
- Better productivity

---

## Summary

VS Code debugging enables developers to inspect Angular applications directly from the editor using breakpoints, watches, and source maps.
