# Installing Angular Language Service

## Install Extension

Open VS Code.

Go to:

```
Extensions (Ctrl + Shift + X)
```

Search for:

```
Angular Language Service
```

Install the extension published by the Angular Team.

---

## Benefits

- Auto Completion
- Template IntelliSense
- Error Detection
- Navigation
- Hover Information
- Template Validation

---

## Start Angular Project

```bash
ng serve
```

---

## Open Debug View

```
Run and Debug

Ctrl + Shift + D
```
